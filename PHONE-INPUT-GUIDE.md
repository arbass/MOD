# Phone Country Selector - Руководство

## Описание
Утилита добавляет профессиональный выбор кода страны для телефонных полей с функциями:
- 🌍 Выпадающий список всех стран мира с флагами
- 🔍 Поиск страны
- 📱 Автоматическое форматирование номера
- ✅ Валидация номера телефона
- 🎯 Приоритетные страны (Украина, США, Великобритания, Германия)

## Установка
Уже установлено и настроено! ✅

## Использование

### На вашем сайте Webflow
Просто убедитесь, что у вас есть поле ввода телефона с `id="phone"`:

```html
<input 
  class="text-field-input w-input" 
  type="tel" 
  id="phone" 
  name="phone"
  placeholder="Enter your phone number" 
  required
/>
```

Утилита автоматически:
1. Найдет это поле
2. Добавит выбор страны с флагами
3. Настроит форматирование и валидацию

### Что добавляется автоматически
- Кнопка с флагом и кодом страны слева от инпута
- При клике на кнопку открывается выпадающий список стран
- Поле поиска в списке стран
- Автоматическое форматирование при вводе
- Валидация (зеленая/красная рамка при правильном/неправильном номере)

### Получение полного номера при отправке формы
Полный международный номер автоматически сохраняется в атрибут `data-full-number`:

```javascript
// В обработчике формы вы можете получить:
const phoneInput = document.getElementById('phone');
const fullNumber = phoneInput.dataset.fullNumber; // Например: "+380123456789"
```

## Тестирование
1. Запустите dev сервер: `pnpm dev`
2. Откройте в браузере: `http://localhost:3000/test-phone.html`
3. Проверьте функционал:
   - Клик на флаг/код страны
   - Поиск стран
   - Ввод номера и форматирование
   - Валидация при потере фокуса

## Настройки

### Изменить приоритетные страны
В файле `src/utils/phoneCountrySelector.ts` измените массив:

```typescript
preferredCountries: ['ua', 'us', 'gb', 'de'],
```

### Изменить стиль валидации
По умолчанию добавляются классы `.valid` и `.error`. Вы можете изменить это в обработчиках событий.

## Важно
- Утилита автоматически скрывается на страницах без поля `#phone`
- Стили intl-tel-input подгружаются через CDN автоматически, ничего вручную подключать не нужно
- Стили интегрируются без конфликтов с Webflow
- Библиотека загружает utils.js с CDN для корректной работы

## Поддержка
Если что-то работает не так, проверьте:
1. Есть ли на странице элемент с `id="phone"`
2. Подключен ли скрипт `dist/index.js`
3. Открыта ли консоль браузера для проверки ошибок
