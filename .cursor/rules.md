# Project Rules and Structure

## Project Structure

### `/seo-schemas/`
Папка для работы с SEO схемами из Webflow. Используется для:
- Хранения экспортированных SEO скем из Webflow
- Внесения текстовых правок в схемы
- Организации SEO-контента перед импортом обратно в Webflow

### `/src/`
Основная папка с исходным кодом проекта.

### `/src/utils/`
Утилиты для работы с Webflow (Finsweet Dev Starter).

## Development Guidelines

### Utils Creation
- Все новые utils для Webflow создаются на основе `util_template.ts`
- Каждая util должна проверять наличие ключевого элемента перед выполнением
- Все новые utils должны быть подключены в `index.ts`
- Комментарии в коде только на английском языке

### Code Style
- Все комментарии в коде на английском
- Никогда не использовать русский язык в коде
- Следовать TypeScript best practices

### Testing
- Всегда тестировать код перед объявлением задачи выполненной
- Убедиться что все работает корректно

## Workflow
1. Проверить доступные MCP перед началом задачи
2. Прочитать этот файл перед каждым действием
3. Дополнять этот файл при необходимости
